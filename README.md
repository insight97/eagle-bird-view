# Bird View POC

Eagle 的白板式媒體瀏覽器概念驗證。它會載入 Eagle 目前選取的圖片與影片，讓使用者在可平移、縮放的白板上瀏覽。

## 安裝與執行

1. 開啟最新版 Eagle。
2. 點選工具列的「外掛」→「開發者選項」→「建立外掛」。
3. 選擇 **Window Plugin**，讓 Eagle 建立一個測試外掛目錄。
4. 將本專案檔案複製到該目錄，取代 Eagle 產生的範例檔案。
5. 在 Eagle 選取一些圖片或 MP4。
6. 開啟 **Bird View**；若選取內容有變化，按「載入目前選取」。

## 操作

- 拖曳空白處：移動白板
- 從圖片或影片任意位置拖曳：移動白板
- 滾輪：以游標位置為中心縮放，最高 1200%
- MP4 中央播放鍵：載入原始影片，控制列位於影片本體下方
- 雙擊卡片：使用 Eagle 的預覽視窗開啟素材
- 顯示全部：把目前所有素材縮放到視窗內
- 100%：保持目前中心點並恢復原始縮放比例

## POC 限制

- 關閉外掛後不保存素材位置。
- Eagle 沒有公開「目前選取變更」事件，因此需手動按「載入目前選取」。
- 影片能否播放取決於 Eagle 內建 Chromium 對該 MP4 編碼的支援；不能播放時仍可雙擊回 Eagle 預覽。
- 尚未做可視範圍虛擬化，建議先以 50～200 個素材測試。
