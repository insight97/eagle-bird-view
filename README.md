# Bird View POC

Eagle 的白板式媒體瀏覽器概念驗證。它會載入 Eagle 目前選取的圖片、影片、MP3 音訊與 PDF，讓使用者在可平移、縮放的白板上瀏覽；也可開啟自動探索，隨機瀏覽未評分素材。

一般圖片先使用 Eagle 縮圖顯示，選取或放大時再載入原始檔；原圖載入失敗或逾時時會保留縮圖並顯示重試按鈕。影片與 MP3 音訊預覽使用 Eagle 縮圖（沒有音訊縮圖時顯示音訊卡片），播放時共用進度、音量與播放／暫停控制。

PDF 先以縮圖顯示外層卡片；雙擊 PDF 或選取後按 Enter 會進入 PDF 白板。PDF.js 先取得首頁尺寸並立即建立完整的虛擬頁面白板，其他頁面的實際比例會在背景補齊；混合尺寸 PDF 只在比例資料完整後更新一次排版。頁面可以像一般素材一樣選取、平移、縮放與旋轉，按 Esc 或工具列的「← PDF」返回原本白板；虛擬頁面不會寫入 Eagle metadata 或白板歷史。

開啟白板時會以 100% 置中第一個媒體。白板只掛載可視範圍附近的素材，平移期間會持續快速補上前進方向的新縮圖；卡片在畫面上高度達到 320px 後便載入原圖。總載入併發最多四張，其中原圖點陣圖同時最多兩張；選取或畫面中央的圖片會先處理並與一張背景圖並行，完成後再由兩張背景圖共同補齊附近清晰度。距離畫面較遠的圖片、影片與音訊會自動釋放。

指標拖曳時會暫時隱藏網格與素材標籤，平滑縮放與聚焦動畫期間則隱藏標籤。所有相機移動途徑都會維持圖片既有畫質，不會在移動中縮回縮圖，也不會啟動新的原圖點陣圖；相機停下後才補上需要的清晰度，並優先處理選取或畫面中央的圖片。若執行環境只能透過完整圖片元素讀取母檔，這項相容退路同樣會延後到相機停下，避免解碼阻塞縮放動畫。超過顯示預算的原圖不會以完整解析度直接繪製，而是先縮成符合目前顯示尺寸的點陣圖；放大超過該尺寸時自動重新產生更清晰的版本，期間畫面保持不閃爍；縮小時則從既有點陣圖產生較小版本，不重新讀取母檔。若點陣圖無法產生，會保留縮圖並提供重試，避免改畫高解析度母檔。這能避免高解析度母檔在移動時造成的重複解碼與合成負載。

素材使用等高對齊列排版：每列維持接近一致的高度、固定間距並依媒體比例填滿版面，最後一列自然靠左，讓畫面緊湊但仍容易掃視。

## 安裝與執行

1. 開啟最新版 Eagle。
2. 點選工具列的「外掛」→「開發者選項」→「建立外掛」。
3. 選擇 **Window Plugin**，讓 Eagle 建立一個測試外掛目錄。
4. 將本專案檔案複製到該目錄，取代 Eagle 產生的範例檔案。
5. 可選擇在 Eagle 選取一些圖片、影片、MP3 或 PDF。
6. 開啟 **Bird View**；外掛會載入目前選取內容。若選取的是資料夾，會包含子資料夾素材，先分批載入，剩餘內容可按「載入更多」；也可等待使用者開啟自動探索。

## 開發驗證

測試分成兩層：`test/` 為單元測試，只驗證單一模組的純邏輯（排版、可視範圍、相機導航、媒體載入、探索候選、資料夾路徑），不需要 DOM；`test/integration/` 則驗證需要瀏覽器環境的行為，包含以 Happy DOM 驅動的元件（標籤編輯器、資料夾選擇器、影片／音訊播放器），以及透過 `test-support/plugin-harness.js` 把 `plugin.js` 接上假 Eagle API 後的端對端流程。新增模組時，`test/script-load-order.test.js` 會確認 `index.html` 的 `<script>` 順序仍能讓每個模組取得相依模組。

執行 `npm run test:unit` 可快速驗證單元測試，`npm run test:integration` 執行整合測試，`npm test` 則會執行全部測試。整合測試會自動將 Happy DOM 預打包至忽略版控的 `.test-cache`，降低掛載磁碟的小檔案載入成本；`npm run test:coverage` 可產生排除該快取的覆蓋率報告（注意 `plugin.js` 由 vm 載入，不會出現在覆蓋率報告中）。

## 操作

- 拖曳空白處：移動白板
- 從圖片、影片或音訊任意位置拖曳：移動白板
- 點擊素材：單選並成為目前操作素材；`Ctrl`／`Cmd`＋點擊可切換單張，`Shift`＋點擊可選取 anchor 到目前素材的連續區間；一般點擊會回到單選，`Esc` 清除選取
- 多選時：中央素材的自動選取會暫停，工具列顯示選取數量；評分、Tag、資料夾操作套用到整個選取集合，媒體播放與 `Ctrl＋Home` 仍只作用於目前操作素材
- 素材右鍵：在 Eagle 中開啟該素材
- 素材上方的 Tag／資料夾按鈕：左鍵探索，右鍵清空白板並載入該 Tag／資料夾的內容
- Eagle 重新選取素材並再次開啟 Bird View：只將尚未在白板上的素材新增到下一列
- 白板替換後：工具列按「上一頁」或按 `Ctrl＋Z` 回到上一個白板階段；按「下一頁」、`Ctrl＋Shift＋Z` 或 `Ctrl＋Y` 前往下一個階段。會保留素材、旋轉、相機位置與目前選取素材。最多保留 10 個階段，切換 Eagle library 時清除歷史
- Eagle 選取資料夾並開啟 Bird View：首批累積至少 120 個已取得素材後顯示，子資料夾在背景載入；若總數少於 120 個則全部查完後顯示；按「載入更多」可繼續分批載入資料夾內的全部素材
- 資料夾內部分查詢失敗時：保留已顯示的素材，載入按鈕會改為「重試載入」，只重試尚未成功的資料夾內容
- 左側資料夾側欄：可搜尋並選取任意資料夾，選取後會清除舊白板並只顯示該資料夾內容，側欄會標示目前選取的資料夾；使用原本的資料夾圖示並沿用 Eagle 的資料夾顏色，預設包含子資料夾，也可關閉此選項；首批累積至少 120 個已取得素材後顯示，若總數較少則全部查完後顯示，剩餘素材可按「載入更多」
- 同時選取素材與資料夾時：優先載入已選取素材
- 自由瀏覽：唯一模式；可拖曳白板，放開滑鼠後自動選取中央素材，視窗中心也會自動選取最近的素材；進入多選後會保留選取集合
- 白板設定：可分別設定平滑移動、平滑縮放、縮放速度、鍵盤操作加速反應與聚焦素材大小；移動速度最高 6000 px/s、縮放速度最高 60×/秒；移動速度會影響方向鍵／WASD 的單次位移，平滑移動按住時會逐步加速、放開後逐步減速；放鍵減速會依速度自動調整並在約 160ms 內結束，略過肉眼難辨的低速尾段後選取畫面中央素材並提早恢復圖片清晰度；設定會記住並在下次開啟時還原
- 影片自動播放：開啟後，選取影片且影片畫面高度達到 320px 時會自動播放；切換選取素材或縮小到門檻以下會暫停
- 設定 Preset：可從工具列快速選擇既有 Preset；在設定面板輸入名稱即可儲存目前設定，也可套用、更新或刪除既有 Preset；重新開啟外掛時會自動套用上次使用的 Preset，若該 Preset 已不存在則回退到上次的一般設定
- 方向鍵或 WASD：移動視野
- Shift＋方向鍵：移動三分之二個畫面；播放影片或音訊時不介入媒體控制
- Ctrl＋方向鍵：播放影片或音訊時 Ctrl＋左／右快轉、Ctrl＋上／下調整音量並顯示百分比；音量會沿用到下一個可播放素材；其他情況切換素材，依所在列高度以設定的聚焦素材大小標準化縮放並置中；跨列聚焦動畫期間會暫時隱藏白板標籤，動畫完成後恢復
- 滾輪：以游標位置為中心縮放，最高 1200%；100% 代表視窗可完整顯示一個媒體
- Ctrl + PageUp／PageDown：以視窗中心放大／縮小；開啟平滑縮放後按住可連續縮放，按住時會逐步加速，放開後會依設定速度自動調整減速，縮放期間暫時隱藏標籤並在完成後更新圖片清晰度
- Home：以目前選取素材為中心，依所在列高度及設定的聚焦素材大小自動縮放並置中；End：縮放至完整顯示目前選取素材所在列
- Ctrl＋Home：將目前播放影片的畫面設為 Eagle 自訂縮圖；圖片、尚未載入畫面的影片或不支援的環境會提示原因，若 Canvas、暫存資料夾或 Eagle API 不可用也會顯示對應問題
- F11：開啟或關閉全螢幕模式
- Tab：開啟或關閉資料夾側欄
- Del：開啟或關閉緊鄰模式；緊鄰模式會縮小素材間距並隱藏非必要資訊，評分與標籤改用數字鍵／T 快捷鍵操作，切換模式時會維持目前選取素材的位置；Home 與 Ctrl＋方向鍵會以較大的比例聚焦素材
- Insert：開啟或關閉自動探索
- 自動探索：縮放至 80% 且最後一列位於畫面內時，載入下一列符合條件的素材
- Enter：播放或暫停目前選取的影片或 MP3 音訊
- Ctrl + Enter：以目前選取素材探索下一列
- 探索下一列：依中央素材的共同資料夾與標籤，選擇兼具關聯與差異性的素材；每次探索只新增一列，持續選取到填滿該列或候選耗盡，候選不足時以目前取得的素材完成未滿列
- AI 探索：可在設定中選擇 AI 佔每列探索素材的比例（0／25／50／75／100%）、相似度上限與探索多樣性強度；AI 素材在基本強度下依 AI Search 回傳順序加入，強度提高後才會抑制同列重複的 Tag／資料夾，其餘一般探索也會同步加強多樣性選取；比例為 0 即關閉，AI Search 不可用時會退回一般探索
- 工具列與素材上方的 Tag／資料夾按鈕：左鍵以該 Tag 或資料夾為條件隨機探索素材，加入目前選取素材列的下方；右鍵可從素材移除該 Tag 或資料夾；旁邊的「＋」可開啟多選編輯器，既有 Tag／資料夾會先勾選，可搜尋並加入新的項目或取消既有項目，按「完成」後一次儲存；工具列 Tag 數量過多時會依可用寬度收合成 `+N`，點擊後可搜尋並選擇全部 Tag
- 自動探索開關：預設關閉；開啟後，沒有素材時載入第一列，放大超過 100% 並查看最後一列時，依目前設定隨機載入下一列素材
- 自動探索設定：可多選檔案類型（圖片／影片／音訊，預設皆選）、資料夾（可包含子資料夾）、精確或範圍評分、指定 Tag（可設定群組內／群組間任一或全部符合）、排除 Tag 與 Tag 數量上限（嚴格小於指定數字）；變更後立即生效，只影響後續探索列
- 雙擊影片：播放或暫停，影片結束後會自動循環播放；雙擊 MP3 音訊可播放或暫停，音訊播放完畢後停止
- PDF 外層卡片會顯示「PDF · 雙擊進入」標示，雙擊即可進入 PDF 白板
- 雙擊 PDF 或對選取的 PDF 按 Enter：進入 PDF 白板，逐頁瀏覽 PDF 內容；按 Esc 或「← PDF」返回原本白板
- PDF 頁碼顯示在頁面上方的 label 與工具列，不會覆蓋 PDF 內容
- PDF 頁面會依白板目前顯示尺寸重新繪製；放大跨過目前解析度後會升級 Canvas，完成前保留舊畫面
- 標題列旋轉按鈕：左鍵向左／右旋轉 90°，右鍵旋轉 45°，不修改 Eagle 原檔
- 評分星號：單選時點擊即可更新 Eagle 評分，再次點擊目前的星等可清除評分；多選時工具列星號會套用到全部素材，再次點擊相同星等可全部清除
- 標籤編輯器：搜尋、建立、新增或移除 Eagle 標籤，按「完成」後儲存
- 數字鍵 1–5：設定目前素材的 Eagle 評分；多選時套用到全部選取素材
- T：開啟目前素材的標籤選單；多選時編輯整個選取集合；輸入後以方向鍵選擇，按 Enter 套用；輸入框為空時按 Enter 完成編輯
- F：搜尋 Eagle 資料夾並編輯目前素材的資料夾；多選時編輯整個選取集合；既有資料夾會先勾選，選取後可加入或移除，按 Enter 完成
- 影片／音訊中央播放鍵：載入原始影片或 MP3 音訊；下方保留細進度條，移到喇叭圖示時顯示音量滑桿與百分比

## 圖片清晰化診斷

若要分析縮放後等待清晰的時間，可在 Eagle 開發者工具 Console 執行 `localStorage.setItem("bird-view-debug", "1")` 後重新開啟外掛。Console 會依序記錄 `original-quality-requested`、`original-load-started` 與 `bounded-raster-built`，其中 `queueWaitMs`、`buildMs`、`totalMs` 可分辨 queue 等待與母檔／raster 處理時間，`priority` 可分辨中央／選取圖片與背景工作；`raster-budget-change-requested` 代表縮放跨過目前 raster 預算，`bounded-raster-resized` 則代表直接從既有 raster 縮小。`original-element-fallback-deferred` 表示完整圖片元素退路因相機仍在移動而延後；若出現 `bounded-raster-unavailable`，其 `source`、`stage` 與 `reason` 可分辨檔案讀取、bitmap 解碼或 canvas 建立失敗。完成後執行 `localStorage.removeItem("bird-view-debug")` 關閉紀錄。

## POC 限制

- 關閉外掛後不保存素材位置。
- 圖片會依 EXIF 方向顯示，影片方向由 Eagle 內建 Chromium 依檔案 metadata 處理。
- Eagle 沒有公開「目前選取變更」事件，選取內容改變後需重新開啟 Bird View。
- AI 探索需要 Eagle AI Search 外掛與可用的 AI Search 服務；服務尚未 ready 時會使用一般探索。
- 支援辨識 MP4、M4V、MOV、WebM、MKV、MP3 與 PDF；影片能否播放仍取決於 Eagle 內建 Chromium 對影片內部編碼的支援，MP3 則取決於內建 Chromium 的音訊解碼能力；PDF 頁面顯示需要外掛目錄中的 PDF.js、worker、CMap 與標準字型資產，且 Eagle 實際版本的本機檔案讀取與 worker 行為仍需在 Eagle runtime 驗證。
- 極大量素材的實際上限仍會受到 Eagle 內建 Chromium、縮圖尺寸與裝置記憶體影響。
