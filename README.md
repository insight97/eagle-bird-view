# Bird View POC

Eagle 的白板式媒體瀏覽器概念驗證。它會載入 Eagle 目前選取的圖片與影片，讓使用者在可平移、縮放的白板上瀏覽；也可開啟自動探索，隨機瀏覽未評分素材。

一般圖片先使用 Eagle 縮圖顯示，選取或放大時再載入原始檔；原圖載入失敗或逾時時會保留縮圖並顯示重試按鈕。影片預覽也使用 Eagle 縮圖。

開啟白板時會以 100% 置中第一個媒體。白板只掛載可視範圍附近的素材，圖片先以縮圖顯示，卡片在畫面上高度達到 320px 後便以最多四張的併發數載入原圖；距離畫面較遠的圖片與影片會自動釋放。

素材使用等高對齊列排版：每列維持接近一致的高度、固定間距並依媒體比例填滿版面，最後一列自然靠左，讓畫面緊湊但仍容易掃視。

## 安裝與執行

1. 開啟最新版 Eagle。
2. 點選工具列的「外掛」→「開發者選項」→「建立外掛」。
3. 選擇 **Window Plugin**，讓 Eagle 建立一個測試外掛目錄。
4. 將本專案檔案複製到該目錄，取代 Eagle 產生的範例檔案。
5. 可選擇在 Eagle 選取一些圖片或影片。
6. 開啟 **Bird View**；外掛會載入目前選取內容。若選取的是資料夾，會包含子資料夾素材，先分批載入，剩餘內容可按「載入更多」；也可等待使用者開啟自動探索。

## 開發驗證

測試分成兩層：`test/` 為單元測試，只驗證單一模組的純邏輯（排版、可視範圍、相機導航、媒體載入、探索候選、資料夾路徑），不需要 DOM；`test/integration/` 則驗證需要瀏覽器環境的行為，包含以 Happy DOM 驅動的元件（標籤編輯器、資料夾選擇器、影片播放器），以及透過 `test-support/plugin-harness.js` 把 `plugin.js` 接上假 Eagle API 後的端對端流程。新增模組時，`test/script-load-order.test.js` 會確認 `index.html` 的 `<script>` 順序仍能讓每個模組取得相依模組。

執行 `npm run test:unit` 可快速驗證單元測試，`npm run test:integration` 執行整合測試，`npm test` 則會執行全部測試。整合測試會自動將 Happy DOM 預打包至忽略版控的 `.test-cache`，降低掛載磁碟的小檔案載入成本；`npm run test:coverage` 可產生排除該快取的覆蓋率報告（注意 `plugin.js` 由 vm 載入，不會出現在覆蓋率報告中）。

## 操作

- 拖曳空白處：移動白板
- 從圖片或影片任意位置拖曳：移動白板
- 素材右鍵：在 Eagle 中開啟該素材
- Eagle 重新選取素材並再次開啟 Bird View：只將尚未在白板上的素材新增到下一列
- Eagle 選取資料夾並開啟 Bird View：素材依名稱自然排序，先載入 120 個素材，按「載入更多」可繼續分批載入資料夾內的全部素材
- 同時選取素材與資料夾時：優先載入已選取素材
- 自由瀏覽：唯一模式；可拖曳白板，放開滑鼠後自動選取中央素材，視窗中心也會自動選取最近的素材
- 白板設定：可分別設定平滑移動、平滑縮放與聚焦素材大小；移動速度會影響方向鍵／WASD 的單次位移，平滑移動放開按鍵後會選取畫面中央素材；設定會記住並在下次開啟時還原
- 設定 Preset：可從工具列快速選擇既有 Preset；在設定面板輸入名稱即可儲存目前設定，也可套用、更新或刪除既有 Preset
- 方向鍵或 WASD：移動視野
- Shift＋方向鍵：移動三分之二個畫面；播放影片時不介入影片控制
- Ctrl＋方向鍵：播放影片時 Ctrl＋左／右快轉、Ctrl＋上／下調整音量並顯示百分比；音量會沿用到下一部影片；其他情況切換素材，依所在列高度以設定的聚焦素材大小標準化縮放並置中
- 滾輪：以游標位置為中心縮放，最高 800%；100% 代表視窗可完整顯示一個媒體
- Ctrl + PageUp／PageDown：以視窗中心放大／縮小；開啟平滑縮放後按住可連續縮放
- Home：以目前選取素材為中心，依所在列高度及設定的聚焦素材大小自動縮放並置中；End：縮放至完整顯示目前選取素材所在列
- F11：開啟或關閉全螢幕模式
- Del：開啟或關閉緊鄰模式；緊鄰模式會縮小素材間距並隱藏非必要資訊，評分與標籤改用數字鍵／T 快捷鍵操作，Home 與 Ctrl＋方向鍵會以較大的比例聚焦素材
- Insert：開啟或關閉自動探索
- 自動探索：縮放至 80% 且最後一列位於畫面內時，載入下一列符合條件的素材
- Enter：播放或暫停目前選取的影片
- Ctrl + Enter：以目前選取素材探索下一列
- 探索下一列：依中央素材的共同資料夾與標籤，選擇兼具關聯與差異性的素材，在目前素材列下方新增一列
- AI 探索：可在設定中限制每列最多加入的 AI 素材數量，設為 0 即關閉；AI Search 不可用時會退回一般探索
- 工具列中的 Tag／資料夾按鈕：以該 Tag 或資料夾為條件隨機探索素材，加入目前選取素材列的下方
- 自動探索開關：預設關閉；開啟後，沒有素材時載入第一列，放大超過 100% 並查看最後一列時，依目前設定隨機載入下一列素材
- 自動探索設定：可多選檔案類型（圖片／影片，預設兩者皆選）、資料夾（可包含子資料夾）、精確或範圍評分、指定 Tag（可設定群組內／群組間任一或全部符合）、排除 Tag 與 Tag 數量上限（嚴格小於指定數字）；變更後立即生效，只影響後續探索列
- 雙擊影片：播放或暫停，影片結束後會自動循環播放
- 標題列旋轉按鈕：左鍵向左／右旋轉 90°，右鍵旋轉 45°，不修改 Eagle 原檔
- 評分星號：點擊即可更新 Eagle 評分，再次點擊目前的星等可清除評分
- 標籤列的「＋」：搜尋、建立、新增或移除 Eagle 標籤，按「完成」後儲存
- 數字鍵 1–5：設定目前素材的 Eagle 評分
- T：開啟目前素材的標籤選單；輸入後以方向鍵選擇，按 Enter 套用；輸入框為空時按 Enter 完成編輯
- F：搜尋 Eagle 資料夾，將目前素材加入選取的資料夾；不會移除素材原有的資料夾
- 影片中央播放鍵：載入原始影片，影片下方保留細進度條；移到喇叭圖示時顯示音量滑桿與百分比

## POC 限制

- 關閉外掛後不保存素材位置。
- 圖片會依 EXIF 方向顯示，影片方向由 Eagle 內建 Chromium 依檔案 metadata 處理。
- Eagle 沒有公開「目前選取變更」事件，選取內容改變後需重新開啟 Bird View。
- AI 探索需要 Eagle AI Search 外掛與可用的 AI Search 服務；服務尚未 ready 時會使用一般探索。
- 支援辨識 MP4、M4V、MOV、WebM、MKV；能否播放仍取決於 Eagle 內建 Chromium 對影片內部編碼的支援。
- 極大量素材的實際上限仍會受到 Eagle 內建 Chromium、縮圖尺寸與裝置記憶體影響。
