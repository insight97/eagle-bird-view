# Bird View POC

Eagle 的白板式媒體瀏覽器概念驗證。它會載入 Eagle 目前選取的圖片與影片，讓使用者在可平移、縮放的白板上瀏覽。

一般圖片先使用 Eagle 縮圖顯示，選取或放大時再載入原始檔；原圖載入失敗時會自動退回縮圖。影片預覽也使用 Eagle 縮圖。

開啟白板時會以 100% 置中第一個媒體。白板只掛載可視範圍附近的素材，圖片先以縮圖顯示，選取或放大到 100% 後便以最多四張的併發數載入原圖；距離畫面較遠的圖片與影片會自動釋放。

素材使用等高對齊列排版：每列維持接近一致的高度、固定間距並依媒體比例填滿版面，最後一列自然靠左，讓畫面緊湊但仍容易掃視。

## 安裝與執行

1. 開啟最新版 Eagle。
2. 點選工具列的「外掛」→「開發者選項」→「建立外掛」。
3. 選擇 **Window Plugin**，讓 Eagle 建立一個測試外掛目錄。
4. 將本專案檔案複製到該目錄，取代 Eagle 產生的範例檔案。
5. 在 Eagle 選取一些圖片或影片。
6. 開啟 **Bird View**，外掛會自動載入目前選取內容。

## 開發驗證

執行 `npm test` 會使用 Node.js 內建測試工具驗證排版、可視範圍、相機導航、媒體載入與探索候選，不需安裝額外套件。

## 操作

- 拖曳空白處：移動白板
- 從圖片或影片任意位置拖曳：移動白板
- 視窗中心會自動選取最近的素材，移動時不會強制置中
- 方向鍵或 WASD：向對應方向移動視野
- Ctrl＋方向鍵：中央影片播放時快轉或調整音量；其他情況下一次移動三分之二個畫面寬度或高度
- 滾輪：以游標位置為中心縮放，最高 800%；100% 代表視窗可完整顯示一個媒體
- Ctrl + PageUp／PageDown：以視窗中心放大／縮小
- Enter：播放或暫停目前選取的影片
- 探索下一列：依中央素材的共同資料夾與標籤，選擇兼具關聯與差異性的素材，在目前素材列下方新增一列
- 雙擊影片：播放或暫停，影片結束後會自動循環播放
- 標題列旋轉按鈕：左鍵向左／右旋轉 90°，右鍵旋轉 45°，不修改 Eagle 原檔
- 評分星號：點擊即可更新 Eagle 評分，再次點擊目前的星等可清除評分
- 標籤列的「＋」：搜尋、建立、新增或移除 Eagle 標籤，按「完成」後儲存
- 影片中央播放鍵：載入原始影片，影片下方保留細進度條；移到喇叭圖示時顯示音量滑桿與百分比

## POC 限制

- 關閉外掛後不保存素材位置。
- 圖片會依 EXIF 方向顯示，影片方向由 Eagle 內建 Chromium 依檔案 metadata 處理。
- Eagle 沒有公開「目前選取變更」事件，選取內容改變後需重新開啟 Bird View。
- 支援辨識 MP4、M4V、MOV、WebM、MKV；能否播放仍取決於 Eagle 內建 Chromium 對影片內部編碼的支援。
- 極大量素材的實際上限仍會受到 Eagle 內建 Chromium、縮圖尺寸與裝置記憶體影響。
